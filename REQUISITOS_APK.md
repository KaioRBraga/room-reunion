# Requisitos — App do painel (tablet)

## Hardware
- Tablet Android, mínimo **Android 7.0 (API 24)**
- RAM: **2GB mínimo / 3GB+ recomendado** 
- Armazenamento: **32gb**
- Câmera (opcional, só pra escanear QR de pareamento)
- Fonte de energia constante (sempre ligado)

## Rede
- IP do servidor acessível na porta 5000/TCP (Wi-Fi ou cabo, tanto faz)
- Sem bloqueio de firewall/VLAN entre a rede do tablet e a do servidor
- IP do servidor fixo (sem isso, todo tablet pareado para de funcionar se mudar)

## Sistema
- Permitir instalação de apps fora da Play Store (sideload)
- Permitir tráfego HTTP simples (sem HTTPS)
- Permissão de câmera (se for usar QR code)
